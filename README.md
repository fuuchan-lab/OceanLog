# 海ログ / OceanLog

小型船舶（モーターボートなど）と水上オートバイ（ジェットスキーなどの特殊小型船舶）で海に出る人のための Web アプリ（PWA）です。
iPhone・Android のブラウザで開き、「ホーム画面に追加」するとアプリとして使えます。

LeadLog・頭痛ログと同じ構成です（React + TypeScript + Vite、Google ログイン、Google ドライブ保存、日英切り替え）。

## 画面（下のメニュー）

| メニュー | 内容 |
| --- | --- |
| 海図 | 現在地（度・分表記）・対地速力・針路。地図（国土地理院・OpenStreetMap・水深）に海図記号（OpenSeaMap: 灯台・ブイ・航路標識）を重ねる。出港／帰港、地点の記録、出港前に近辺の海図をオフライン用に保存。「記録一覧・書き出し」もここから |
| 波・気象 | （出港前は出航地、出港後は現在地の情報）**航海の安全**（気象庁の注意報・警報、出航地が干潮危険潮位になるまでの時間、日没までの時間、遅くとも帰路につく時刻、波高の危険予測、気圧の急な低下、免許・船検の期限）・風（Windy のマップも表示）・波・うねり・海水温・海流・天気と気圧（頭痛ログと同じ推移グラフと判定） |
| 日没・干満 | （出港前は出航地、出港後は現在地の情報）日の出・日の入り・薄明（端末で計算）、月齢と潮の呼び名（大潮など）、出航地と現在地の潮位グラフ・満潮・干潮 |
| 資格・船舶 | 船の種類（小型船舶／水上オートバイ）、船名・船舶番号・長さ・幅・深さ・定員・船外機の馬力・最高速度・危険な波の高さ・船の写真。小型船舶操縦免許証・船舶検査手帳の写真（LeadLog の名刺と同じ撮影・四隅の補正・文字の読み取り）。免許の種類・次の更新日、次回の船舶検査。期限の1か月前から「！」でお知らせ |
| 設定 | アカウント、出航地（マザーポート: 地図・地名検索で位置を選ぶ、干潮危険潮位・平均水面の高さ Z0）、風速の単位、自分で用意した海図タイル、言語、配色、データの出典 |

## 航行モード（航跡の記録）

- 「出港」を押すと「航行モード」になり、押した場所から記録を始め、**1分おき**に位置を点で残す。
- 航行モードの間は、天気・波・潮・日の出の情報が現在地の情報になる（それ以外は出航地の情報）。
- 出港地点から 300m 以上離れた後、出港地点の 100m 以内に戻ると**自動で帰港**にし、航行モードを終える。出港した場所と違う港に帰った時は「帰港（航行モード終了）」ボタンで終える。
- Web アプリは、**画面に開いている間だけ**位置を受け取れる（別のアプリに切り替えたり画面を消したりすると、ブラウザが位置情報を止める。特に iPhone）。
  次に開いた時から記録が続き、閉じていた区間は海図に点線で出る。記録中は画面が消えないようにしている（Wake Lock）。
  画面を消しても記録し続けるには、ネイティブアプリ化（Capacitor など）が必要。

## データの出典（無料で、権利のゆるいものだけ）

| 用途 | 出典 |
| --- | --- |
| 天気・風・気圧・波・潮位の予報 | [Open-Meteo](https://open-meteo.com/)（CC BY 4.0。API キー不要。非商用は無料） |
| 注意報・警報 | 気象庁ホームページ（出典を明記して利用） |
| 位置 → 市区町村 | 国土地理院 逆ジオコーダー |
| 地名・住所の検索 | 国土地理院 地名検索 |
| 地図・航空写真 | 国土地理院（出典を明記して利用） |
| 地図 | OpenStreetMap（ODbL。一括ダウンロードは規約で禁止のため、オフライン保存の対象外） |
| 海図記号 | OpenSeaMap（CC BY-SA） |
| 水深 | GEBCO |
| 風のマップ | Windy.com 公式の埋め込み表示（開いた時だけ読み込む） |
| 暗岩・洗岩・沈船など | OpenSeaMap（OpenStreetMap の Overpass API、ODbL）。日本は登録が少ない |
| 海しる（任意） | 海上保安庁の海しる API。アカウント登録はなく、**使う人がそれぞれ**「利用方法」ページの試用キーか、海洋情報部の問い合わせフォームで発行を受けた自分のキーを設定に入れる（キーは端末と、ログイン中は自分の Google ドライブの prefs.json に保存し、同じアカウントの端末で共通）。表示中は利用規約の注意書きを出す |
| 日の出・日の入り・月齢 | 端末の中で計算 |

C-MAP・Navionics などの有料の海図は使っていません（Web に組み込める公開 API がなく、ライセンスが必要なため）。
利用の許可を得た海図タイルがあれば、設定の「自分で用意した海図タイル」で重ねて表示できます。

## Google ドライブのフォルダー（OceanLog）

| ファイル | 内容 |
| --- | --- |
| `marks-<端末ID>.json` | その端末が最後に変更した地点 |
| `track-<航跡ID>.json` | 航跡（1回の航海） |
| `profile.json` | 出航地・船の情報・書類の一覧・期限（全端末で共通） |
| `prefs.json` | 設定: 単位・地図・海しるのキーと項目・言語・配色（全端末で共通。まとまりごとに新しく変えたほうを残す） |
| `photo-<ID>.jpg` | 船・書類の写真 |
| `Export/OceanLog_*.gpx` など | 書き出したもの |

書き出しは GPX・KML・CSV・GeoJSON（端末に保存・共有、または Google ドライブに保存）。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト（node --test）
npm run lint     # oxlint
npm run build    # dist/ に出力
```

`main` に push すると GitHub Actions で GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

公開先: https://oceanlog.doitmyself.net/ （GitHub Pages ＋ Value-Domain の CNAME。`public/CNAME`）
- Value-Domain で CNAME `oceanlog` → `fuuchan-lab.github.io` を設定する
- GitHub の Settings → Pages の「Custom domain」に `oceanlog.doitmyself.net` が入り、「Enforce HTTPS」をオンにする

### Google ログイン

当面は LeadLog と同じ OAuth クライアントを使います（承認済みの JavaScript 生成元に `https://fuuchan-lab.github.io` が登録済みなので、
GitHub Pages の `https://fuuchan-lab.github.io/OceanLog/` ではそのまま使えます。ただしログイン画面のアプリ名は「LeadLog」と出ます）。
`https://oceanlog.doitmyself.net` で Google ログインを使うには、その OAuth クライアントの「承認済みの JavaScript 生成元」に `https://oceanlog.doitmyself.net` を追加してください。
OceanLog 専用にする場合は、Google Cloud でプロジェクト「OceanLog」と OAuth クライアント（Web）を作り、Drive API を有効にして、
リポジトリの Variables に `VITE_GOOGLE_CLIENT_ID` を入れてください（ローカルは `.env.example` を `.env.local` にコピー）。

### 注意

表示する情報は予報や計算による目安です。航海用の海図・潮汐表の代わりにはなりません。出港の判断は、最新の公式情報と実際の海の様子を見て、船長の責任で行ってください。
